# باب 3: LLM منصوبہ بندی

## جائزہ

LLM (Large Language Model) منصوبہ بندی روبوٹ کو انسانی زبان کے حکم کو سمجھنے اور اس کے مطابق کام کرنے کی اجازت دیتا ہے۔ یہ منصوبہ بندی ویژن اور ایکشن کے ساتھ کام کرتی ہے۔

## LLM کی خصوصیات

- **زبان کی سمجھ**: انسانی زبان کو سمجھنے کے لیے
- **منصوبہ بندی**: کام کرنے کے لیے
- **کارروائی**: حکم پر عمل کرنے کے لیے
